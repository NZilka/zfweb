# Lessons Directory

This directory contains lesson documentation created after each PR. Each lesson teaches what was built and why, helping build understanding of the codebase over time.

## Naming Convention

Files are named: `{pr-number}-{feature-name}.md`

Examples:
- `01-database-schema.md`
- `02-discount-codes.md`
- `14-checkout-discounts.md`

## Lesson Structure

Each lesson should include:
- **What We Built** - Description of the feature
- **Why This Approach** - Architectural decisions and trade-offs
- **Key Concepts** - Important patterns or techniques used
- **Code Walkthrough** - Explanation of key code
- **Testing Strategy** - How the feature is tested
- **What You Learned** - Summary of new knowledge
